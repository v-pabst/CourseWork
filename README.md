Курсовой проект по предмету "Введение в проектную деятельность". В.А.Пабст ЕТ-142

Глава 1. Датасет с табличными данными
Задача: прогнозирование исхода хоккейных матчей НХЛ на основе статистических данных.
Датасет: https://www.kaggle.com/datasets/flynn28/nhl-games-database
Файл HockeyGames.py - код для первичного анализа

Глава 2. Датасет с временными рядами
Задача: поиск аномалий для выявления поломок и неисправностей промышленного оборудования.
Датасет: https://github.com/waico/SKAB
Файл SKAB.py - код для первичного анализа

Глава 3. Датасет с изображениями
Задача: распознаванияe граффити на объектах городской среды.
Датасет: https://noonv.github.io/KGD//
Файл Graffiti.py - код для первичного анализа

Глава 4. Датасет с текстовыми данными
Задача: суммаризация новостных статей.
Датасет: https://huggingface.co/datasets/IlyaGusev/gazeta
Файл Gazeta.py - код для первичного анализа
